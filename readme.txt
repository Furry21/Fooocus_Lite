3. ПОДКАЧКА БИБЛИОТЕК PYTHON (Для терминала)
--------------------------------------------------------------------
Когда ты первый раз запустишь нашу кнопку запуска ./run.sh, система 
может ругнуться, что внутри твоего виртуального окружения (venv) нет 
нужных библиотек. 

Если что-то пойдёт не так, просто открой терминал в папке проекта, 
активируй окружение командой:
source venv/bin/activate

И доустанови все нужные шестерёнки одной командой:
pip install uvicorn fastapi diffusers controlnet_aux pillow torch transformers accelerate peft python-multipart

🚀 ИНСТРУКЦИЯ И ОПИСАНИЕ НАШИХ КНОПОК:
--------------------------------------------------------------------

🛠 КНОПКА 1: Запуск сервера (файл run.sh)
----------------------------------------
Что делает: Автоматически переходит в нужную папку, активирует чистое 
виртуальное окружение (venv) и одной командой поднимает наше алхимическое 
ядро на FastAPI/Uvicorn. Больше никаких ручных команд в терминале!
Как использовать: 
- Откройте терминал в папке проекта и запустите команду: ./run.sh
- Или дважды кликните по созданному ярлыку Foooocus.desktop.
- После запуска откройте браузер по адресу http://127.0.0.1:8000
- Введите Prompt и нажмите большую кнопку "🌸 Создать арт".

🛑 КНОПКА 2: Остановка сервера (файл stop.sh)
--------------------------------------------
Что делает: Поскольку сервер запускается в фоновом режиме и терминал 
не висит перед глазами, эта кнопка — наш экстренный тормоз. Она находит 
процесс Python, который занял порт 8000, безжалостно уничтожает его и 
ПОЛНОСТЬЮ освобождает видеопамять вашей видеокарты. 
Как использовать:
- Когда закончили генерировать арты, просто запустите команду: ./stop.sh
- Чтобы убедиться, что нейросеть ушла спать, обновите страницу в браузере. 
  Если сайт перестал открываться — всё прошло успешно, GPU свободна!
